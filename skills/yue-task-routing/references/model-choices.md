## First small trial (2026-09-05)

Astra medium and Luna Max each completed one identical synthetic local repair and one fixed-input status report with no corrective rerun. Both repairs passed the same 12 acceptance cases. Recorded elapsed times: Astra 65.4s / 14.5s, Luna 87.7s / 25.5s (repair / report), including startup and scheduling. Runtime records confirmed both model/effort settings. This is one observation per task, not a stable speed ranking or production benchmark. Attributable dollar cost and weekly quota cost remain unknown; different cache hits prevent naive token-to-price comparisons. Child startup input remained around 35k tokens even without inherited conversation history: do not delegate tiny work automatically. These tests did not evaluate this Skill's routing behavior or orchestration benefit.
